# Battery and keyboard

The **Battery & keyboard** page has the charging and keyboard options from Lenovo Vantage. Each one is a switch.

- **Battery conservation**: stops charging at about 80%. Turn it on if your laptop is usually plugged in: it slows
  battery wear.
- **Always-on USB charging**: charges phones and other devices from the USB ports while the laptop is off or asleep.
- **Fn lock**: F1 to F12 work as function keys without holding Fn. The media keys then need Fn.
